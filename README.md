# To-Do Life Dashboard

Contoh academic/learning project untuk portfolio JokiTugasMang.

## Teknologi
- HTML5
- CSS3
- Vanilla JavaScript
- LocalStorage

## Cara menjalankan
Buka `index.html` langsung di browser.

## Fitur
- Tambah tugas
- Prioritas
- Tandai selesai
- Hapus tugas
- Progress otomatis
- Penyimpanan LocalStorage
- Responsive desktop/mobile

## GitHub Pages
Upload semua file ke repository GitHub, lalu aktifkan:
Settings → Pages → Deploy from branch → main → root.
